# P4 小说性能测量

测量日期：2026-09-23。源文件是本机《七日の喰い神》的 Markdown 文本，来源登记见 [sources.md](../sources.md)。测量程序为 release 配置的 `kotoclip-nlp`；代码基线 `ec34be5`，本轮修正了 `DocumentPlan` 的短行分窗行为。原始逐窗统计保存在 `.agents/analysis/p4-novel-10.json`。

## 语料与划分

选取第一话正文开头 10,010 个 Unicode 字符，排除章节标题和图片引用，保留段落、对话和原有注音。沿空行选择十处相邻的段落边界，形成十段连续文本，每段 965–1,053 个原文字符。原文经过注音预处理后，共有 9,027 个分析字符。十段依次进入同一个常驻进程的独立文档会话；每段产生两个连续窗口，共 20 个窗口，长度上限为 768 个预处理字符。逐段结果和窗口范围如下：

| 段 | 原文字符范围 | 字符数 | 分析窗口 | 耗时（秒） |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0–1,004 | 1,004 | 2 | 26.24 |
| 2 | 1,004–1,991 | 987 | 2 | 5.02 |
| 3 | 1,991–3,000 | 1,009 | 2 | 8.89 |
| 4 | 3,000–4,001 | 1,001 | 2 | 8.38 |
| 5 | 4,001–5,000 | 999 | 2 | 6.42 |
| 6 | 5,000–5,996 | 996 | 2 | 6.17 |
| 7 | 5,996–6,992 | 996 | 2 | 5.36 |
| 8 | 6,992–7,957 | 965 | 2 | 6.16 |
| 9 | 7,957–9,010 | 1,053 | 2 | 5.16 |
| 10 | 9,010–10,010 | 1,000 | 2 | 5.51 |

相邻段落首尾相接，十段拼接与截取的正文完全相同。每段预处理后的窗口范围连续、没有缺口或重叠，且均未超过 768 字符。`DocumentPlan` 过去优先选择窗口内首个换行；小说短行因此形成过多窗口。现按接近上限的行界划分，保留原文和注音坐标。

## 性能统计

总耗时 84.35 秒；首段冷启动 26.24 秒，后九段合计 57.05 秒，中位数 6.16 秒、P95 8.89 秒。20 个窗口全部完成，GiNZA 和 KWJA 各 20 次均成功，缓存命中均为零。输出包括 5,726 个 token、3,534 条活用链和 456 个构词节点；计数包含窗口上下文，统计口径见原始结果。

| 阶段或来源 | 20 窗口累计 | 单窗口中位数 | 单窗口 P95 |
| --- | ---: | ---: | ---: |
| UniDic | 3.82 秒 | 16 毫秒 | 36 毫秒 |
| 基础统一 | 70 毫秒 | 3 毫秒 | 7 毫秒 |
| 外部来源（含首次加载） | 75.88 秒 | 2.37 秒 | 7.59 秒 |
| 来源统一 | 1.06 秒 | 46 毫秒 | 104 毫秒 |
| GiNZA 请求 | 17.83 秒 | 828 毫秒 | 1.60 秒 |
| KWJA 请求 | 60.43 秒 | 2.37 秒 | 7.14 秒 |

来源请求并行执行，GiNZA 与 KWJA 的累计耗时不能相加作为总耗时。外部来源阶段累计约占本次总耗时的 90%；热态长窗口主要由 KWJA 决定。首个窗口的外部来源阶段为 21.58 秒，其中模型初始化占据显著时间；首个窗口的 UniDic 阶段为 3.51 秒，后续窗口的中位数为毫秒级。

Windows 工作集采样峰值约 2.59 GiB（Rust 进程峰值约 1.02 GiB、两个主要 Python 进程分别约 1.02 GiB 和 0.57 GiB）；采样到的 CPU 时间累计 446.41 秒。标准输入发送约 99 KB，标准输出接收约 91.9 MiB，共 406 次响应。原始结果保存每段窗口范围、阶段耗时、来源状态与缓存状态、资源进程峰值及传输量。后续优化优先评估 KWJA 长窗口耗时和会话响应体积；内存数值使用进程工作集口径。

## 复现

```powershell
cargo build --release -p kotoclip-core --bin kotoclip-nlp
python -X utf8 scripts/benchmark_p4_novel.py
```

脚本默认使用登记的本机小说文件，输出位于 `.agents/analysis/p4-novel-10.json`。可通过 `--source`、`--binary` 和 `--output` 指定其他路径；报告保存输入及程序的 SHA-256 摘要、机器信息与逐窗原始测量。测量范围是 P4 的三来源分析，不包含词典查询和阅读器渲染。
