# 质量验收

## 完成标准

模块完成包含四项证据：实现进入编译、应用服务实际调用、桌面交互可达、代表用例通过。完整交付按[功能范围](README.md)逐项验收，并保留文档版本、程序版本、资源版本和结果。

验收分为协议正确性、语言质量、交互与持久化、性能和桌面启动。各项分别报告，识别数量和查询命中率使用明确分母。

## 协议与语言质量

| 对象 | 检查内容 |
| --- | --- |
| 正文与坐标 | 原文重建、Unicode scalar 范围、ruby、章节和图片定位 |
| 来源结果 | 正文身份、模型任务、词法字段、结构与关系完整性 |
| token 对齐 | 各类映射、gap、边界分歧、表面串差异和关系端点 |
| 形态与构词 | 活用链、词汇／功能所有权、查询形、整体词绑定 |
| 文节与句法 | 边界、主辞、依存、小句、基本句、谓语及论元范围 |
| 语法与表达 | 类型、命中范围、义项、解释、非连续间隔与硬边界 |
| 词典 | 表记准入、读音一致性、矩阵可用性、正文结构与关系导航 |

代表集覆盖书面叙事、对话、缩略、专名、标点、长句和混合注音。人工期望记录实际语句、来源和判断依据。外部模型结果作为来源输出参与比较，人工复核决定语言质量结论。

当前已知错误转换为小型回归样本，分别覆盖正例、反例和边界。规则修改验证所属规则族；公共坐标、来源或调度修改扩大到相应完整流程。

## 分层差分

差分在固定正文与资源清单上比较两侧真实应用分析。观察层包含词元、活用、构词、文节、句法、语法、表达、查询目标、词典内容和阅读投影。

配对使用文档出现、字符范围与语义身份；来源和算法版本作为两侧元数据。字段变化记录修改，词界变化按完整重叠范围组织结构替换。影响字符数使用区间并集，同一变化的下游传播保留依赖引用。

来源或准备规则变化时重新分析相关领域。局部规则变化依据规则条件和上下文定位影响范围，再执行两侧正式分析。选择式结果与完整分析比较，验证影响范围的覆盖性。

## 审计产物与界面

每轮保存清单、摘要、变化、分页阅读数据、验收结果和生命周期状态。分页结果包含两侧阅读投影及相应的查询快照或固定资源引用。历史查看根据该侧版本恢复内容。

桌面审计提供历史选择、变化导航、双侧阅读、词典／语法查看及差异原因。机器报告与界面读取同一组产物，实体计数、影响字符数和查询变化分别展示。

缓存和分页产物设置容量上限，保存重建信息和清理状态。用户书库与个人数据独立于审计临时空间。

## 性能与异常

测量分别记录冷启动、模型加载、首批正文、结构追加、章节跳转、前台查词、规则更新和再次打开文档。报告固定机器、版本、资源、文本规模、重复次数、中位数与 P95。

本机 Python 进程与 Rust 主程序合计统计工作集、CPU、磁盘和 IPC 数据量。模型复用、队列上限及取消效果通过实际运行测量；发布阈值依据接入后的可用性基线确定。

异常验收包括解释器路径失效、词典或模型缺失、provider 超时／退出、错误坐标、旧请求迟到、缓存失效、磁盘写入失败和更新版本冲突。每项检查用户可见状态、受影响范围及恢复操作。
