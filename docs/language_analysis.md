# 语言分析

## 对象与依赖

应用分析在统一词元、来源结构和明确的知识目录上建立阅读单位。各层保留成员、精确命中范围、整体覆盖范围、来源和决定；查询及展示通过这些引用取得解释。

| 对象 | 定义与用途 |
| --- | --- |
| 形态素 | UniDic 在正文中的词法出现，保存词元、词性与形态字段 |
| 活用链 | 词汇核心或功能用言及其有序活用过程 |
| 构词候选 | 多个形态素的构词关系、词头与形式生成方式 |
| 词汇整体 | 经结构和词典证据确认、绑定词条的整体词 |
| 文节 | 来源分析给出的结构单位，保存主辞、功能成分与依存 |
| 阅读单位 | 面向胶囊和查询的应用分组，引用词汇整体、活用链及文节 |
| 基本句、小句、句子 | 各自保持语言学类型、成员和关系，供上下文解释使用 |
| 语法实例 | 正文中某概念及义项候选的实际实现 |
| 表达实例 | 惯用语、语法构式或非连续呼应的精确命中 |

基础顺序为活用分析、构词及词汇候选、阅读分组、语法与表达识别、知识解释和展示投影。来源文节与依存可供各应用阶段读取。每条规则声明实际依赖，增量执行从受影响的首个阶段开始。

## 活用与词形

活用链保存词汇／功能所有权、核心、成员、有序 operator、连接形、实际表记、显示原型、辞书形和查询形。一个 operator 记录输入状态、输出状态、实际范围及解释证据。

例如 `行かせられなかった` 以同一谓词链组织使役、受身等候选、否定和过去。`読んでくださった` 中的词汇核心与功能用言分别拥有活用链，语法实例引用其实际成员。`静かな` 的显示原型、内部辞书形与查词形式按用途保存。

正文颜色与解释范围由所有权决定：词汇活用随词汇核心展示，功能用言活用随所属语法实例展示。多义形态保留候选及上下文证据，用户选择产生可撤销的实例决定。

## 构词与词典整体词

构词候选由 provider 的复合词结果和类型化应用规则产生，记录成员、词头、输出词性、查询形式及结构证据。词典验证检查规范词头、读音、词性、记录类型和实际正文。

候选成立后绑定确定的词典记录，整体查询复用该绑定。生产型构词同时保留内部成分查询。例如数量表达可以具有构词结构，词典查询则按实际可用的整体词条或成分组织。

多个来源的同范围候选合并证据；部分重叠候选进入竞争关系。成立、待定、拒绝及原因均可复核。词汇证据影响阅读分组，来源 token 和来源文节继续保留。

## 文节与句法

统一层保存来源文节、主辞及依存；应用层以活用链、词汇整体和构词关系生成阅读单位。一个阅读单位可以关联多个来源节点，内部形态素仍可单独命中。

句子范围、引号域、基本句和小句分别建模。基本句保存自身主辞与来源标签；小句保存谓语、成员、接续和嵌套关系。述语项结构保存谓语、论元、角色和省略标记；实体、照应和篇章关系引用相应节点。模型实际提供的结果通过共同证据协议进入结构查看和相关解释。

边界选择检查范围、成员连续性、句界、引号和关系端点。多来源分歧由明确策略选择默认视图，并保留候选供复核。跨句关系遵循所属任务的范围约束。

## 语法识别与知识目录

语法模块分为识别、知识目录、讲解内容和查询服务。知识身份按下列层次组织：

| 身份 | 内容 |
| --- | --- |
| `concept` | 语法概念、分类、等级和关系 |
| `sense` | 语义用法、成立条件与解释 |
| `realization` | 概念在词形和结构上的实现变体 |
| `rule` | 结构条件、命名捕获、正反例及来源 |
| `occurrence` | 本句范围、成员、捕获、活用链和义项决定 |
| 讲解内容 | 版本化正文、例句、来源和核验状态 |

识别先取得助词、助动词、补助用言等功能身份，再组合结构条件和活用链生成语法候选。规则使用 UniDic 字段与统一对象；编译器校验未知字段、知识引用、捕获、正反例和版本。

正文讲解按精确 occurrence、concept 和 sense 查询，并绑定本句捕获及词形信息。文法库独立支持主动搜索、详情和核验状态查看。讲解以简洁说明为默认，形态变化和复杂组成按实际需要展开。

功能语素未能确定概念或义项时，保存待定状态与原因。质量报告分别统计功能身份、语法命中、义项选择、解释可用性及未解释实例。

## 表达与实例修正

表达按惯用语、语法构式和非连续呼应分类。词汇整体进入构词与词典对象；表达保存自身语义、成员、命中区间和成立证据。

连续表达保存词汇整体、活用链和句法关系。非连续表达保存多个有序命中范围及其基本句、小句、句界、段界和引号域关系。正文高亮和导出定位使用实际命中范围，整体范围用于上下文组织。

用户可以对具体出现提交结构或解释修正。修正引用正文锚点、原分析签名、所选对象和理由；文本或模型更新后重新校验定位与适用性，失效记录进入待复核状态。

## 验收与入口

代表用例覆盖 `見えなかった`、`記録された`、`分類し`、`読んでくださった`、`静かな`、`行くな`、`警察署`、数量表达和跨文节惯用语。每例同时检查实际范围、所属层、查询形式、解释和修改后结果。非连续用例覆盖跨句、跨段、引号及自由间隔。

基础对象位于 [morphology.rs](../crates/kotoclip-nlp/src/morphology.rs)、[formation.rs](../crates/kotoclip-nlp/src/formation.rs)、[bunsetsu.rs](../crates/kotoclip-nlp/src/bunsetsu.rs)、[clause.rs](../crates/kotoclip-nlp/src/clause.rs)与[grammar.rs](../crates/kotoclip-nlp/src/grammar.rs)。知识资源位于 [grammar](../crates/kotoclip-core/resources/grammar/)。
