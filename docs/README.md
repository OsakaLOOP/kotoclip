# 当前设计

本组文档定义 Kotoclip 的统一目标模型。实施状态集中记录在 [TODO](TODO.md)，各模块正文采用目标协议描述，代码入口用于定位现有基础。

## 交付目标

完成语言分析与应用模块接入，使用户能够在 Windows 桌面应用中导入和阅读日文书籍，查询词汇与语法，编辑表达规则，维护个人状态，并导出选中内容。功能恢复以已经确定的模块范围为准。

应用使用本机 UniDic、GiNZA、KWJA 及其配套词典和模型。GiNZA、KWJA 通过本机 Python 环境执行，Rust 统一管理请求和结果。初次配置明确选择解释器与资源目录，后续从桌面应用启动并离线分析。

## 完整功能范围

| 模块 | 用户可用结果 |
| --- | --- |
| 输入与书库 | 导入 EPUB、打开 Markdown／文本、书架管理、继续阅读 |
| 语言分析 | 注音、形态、复合词、文节、句子、小句及外部模型结构结果 |
| 阅读与查询 | 阅读胶囊、整体与成分查词、三词典切换、表记选择、正文关系导航 |
| 语法与表达 | 活用说明、精确语法讲解、文法库、连续与非连续表达 |
| 用户编辑 | 范围选择、实例修正、复核及撤销 |
| 个人状态 | 已知状态、曝光记录、熟悉度显示、词典顺序、阅读设置 |
| 摘录与输出 | 收藏和选中内容管理、上下文与释义导出 |
| 词典助手 | 用户主动请求候选消歧，查看并采用建议 |
| 质量工具 | 分层差分、双侧阅读与查询、历史报告和性能诊断 |
| 桌面运行 | 本机依赖检查、资源配置、可执行产物、重启后恢复状态 |
