# 桌面功能验收清单

本清单覆盖当前设计的完整功能范围。状态与实际证据分别记录；开发期间按受影响模块选择短例，P10 在最终产物上执行全部桌面场景。

## 执行条件

使用 `data/validation/refractor_source.txt` 的指定片段及 [NLP 行为基线](nlp_behavior.md) 中的边界例。书库场景使用含三章、ruby 和图片的小型 EPUB；长文档调度使用重复短段组成的合成文档。个人数据迁移使用既有数据库副本。每项记录程序、资源版本、输入、实际结果及产物路径。

## 协议与来源

| 编号 | 操作 | 期望与证据 |
| --- | --- | --- |
| A01 | 对新闻、缩略、文语、法律及三组人工短例执行三来源观察 | 保存原始字段、版本、完整正文摘要；命令 `scripts/probe_nlp_behavior.py` |
| A02 | 在桌面输入第九段并分析；连续分析第二组；切换来源和实体类型 | 基础正文先显示，两来源真实结构可查看；两次请求的模型 PID 相同；`validate_provider_desktop.mjs`、`validate_nlp_integration.py` |
| A03 | 检查 `ｶﾞ`、`が`、`㍿`、`𠮷`、空格和末尾换行；检查 `時折` 的内部切点 | 原始／规范化范围、四类多对多分组、gap、部分覆盖诊断和关系端点准确；来源映射专项结果 |
| A04 | 输入重复句、跨句照应、引语与叙述混排；比较来源分歧 | 重复句出现身份独立；外指保持类型；基本句／小句、内部主辞／依存分别可查；保留候选和选择理由 |
| A05 | 打开合成长文档，跳到后部，再取消、切文档、重试和关闭 | 请求范围优先；迟到更新经文本版本、任务代次和基准版本校验；前台查询可用；会话事件记录 |
| A06 | 冷分析、再次打开、修改规则、修改个人状态、切换资源版本 | 相同输入得到相同规范结果；按声明依赖失效；缓存容量有上限；比较结果与缓存统计 |

| A13 | 调整词典顺序、默认选择；制造慢响应后移到另一词；滚动卸载锚点 | 设置持久；迟到响应结束于原请求；浮层及时关闭或保持正确目标；窄窗口和长内容无溢出 |

## 多粒度查询专项（下一模块）

以下为待执行验收，分别记录人工期望、实际目标、所选词典记录及失败原因。P4 的基础对象检查与本表的查询聚合、决定及桌面行为分别记录。

| 编号 | 操作 | 期望与证据 |
| --- | --- | --- |
| A28 | 在方向転換、教科用図書及独立增补样本中逐位置切换粒度 | 最大合理整体、教科用等中间子词、教科／用／図書等成分按人工期望可达；同范围等价目标合并结果，交叉备选保留。 |
| A29 | 核验見渡す、這い上がる等单 token 复合词的内部成分 | 先确认有词汇意义的拆分，再检查内部范围与还原形；来源 token 稳定。人工选区查询有独立入口，自动拆分正确性单独记录。 |
| A30 | 查询読みませんでした、掲載された、覗かれてる、読んじゃった、読んどく | 默认词元依次依据読む、掲載する／掲載、いる、しまう、おく；形态说明使用规范形式，矩阵包含基本形结果，实际读音及各组表记 ID 一致。 |
| A31 | 核验模型未提出的词汇、整体无记录、拼接读音错误及未知词 | 受限词典发现得到有依据的范围；未收录、读音冲突、错误范围及执行失败分别归因；子词和原子目标持续可查。 |
| A32 | 对教科用の図書、含括号的会社員女性、数字时间串及跨空行短语查询 | 默认选择符合词汇边界；数字读音单独核验；惯用语或跨助词表达具备声明的接续条件。 |
| A33 | 在基础结果、来源追加、切章、缓存恢复及快速悬浮间切换整体和成分 | 目标携带会话、单元及产物版本，过期结果正确结束；相同稳定输入得到相同目标、矩阵及记录，粗细粒度高亮与正文一致。 |
