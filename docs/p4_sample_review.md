# P4 样本输出复核

日期：2026-09-21。复核对象是 `data/validation/refractor_source.txt` 的十个段落，覆盖历史叙述、文语气象、拟人叙述、法律条文、告知文、新闻、气象新闻、议论、口语缩略和心理叙述。每段通过文档会话取得 UniDic、GiNZA、KWJA 的实际结果；完整结果保存在 [`p4-sample-review.json`](../data/validation/p4-sample-review.json)，逐段原始响应保存在本机 `experiments/p4-sample-review/`。

本轮得到 980 个字符、634 个 UniDic 词元、20 个外部构词节点和 204 个功能语素候选。当前语法表达层没有产生已识别实例，说明现有结果可以作为输入证据，尚未完成应用层组合与义项判断。

## 原始输出能提供什么

UniDic 是词形和查询的主来源。十段结果稳定提供 `pos1` 至 `pos4`、`cType`、`cForm`、`lemma`、`orthBase`、`kana`、`kanaBase`、`iType`、`iForm`、`fType`、`fForm`，并保存词条及词元 ID。连续活用能够直接从范围恢复，例如：

| 正文 | UniDic 成员 | 可利用信息 |
| --- | --- | --- |
| `掲載された` | `掲載／さ／れ／た` | サ変动词、受身助动词、过去助动词及各自连接形 |
| `発展せしめる` | `発展／せ／しめる` | 使役形式的词法成员和文语连接 |
| `読んでくださった` | `読ん／で／くださっ／た` | 词汇核心、接续助词、补助用言、过去助动词 |
| `専有してしまっている` | `専有／し／て／しまっ／て／いる` | サ変词、补助用言链、进行状态 |
| `支払わなければならない` | `支払わ／なけれ／ば／なら／ない` | 否定条件和义务表达的完整成员 |

UniDic 的字段仍是原子证据。当前 `morphology::collect` 每个词元建立一条独立链，只读取词元范围和两个活用字段；634 条链中包含标点，`非自立可能` 也没有进入功能语素筛选。应用层需要以词元顺序和连接字段组装链，同时保留每一个成员的查询形和所有权。

GiNZA 的正式 token 流采用 Sudachi C 模式。`sub_tokens` 中的 A／B 模式成分只是 tokenizer 保留的诊断信息，例如 `見渡す` 的 `見／渡す`、`這い上がる` 的 `這い／上がる`；适配器没有调用重切分器，应用不会将它们当作词元。外部 compound span 提供整体范围和正式 C 模式 token 的成员关系，例如 `方向転換`、`教科用図書`、`線状降水帯`、`神戸市`。`線状降水帯` 的 A／B 两套成分只记录在来源原始字段中，P4 不将其作为竞争候选。

KWJA 的基本句和谓语节点提供结构标签，适合补充语法候选的上下文条件。样本中可观察到 `時制`、`モダリティ-意志`、`モダリティ-评价`、`敬語`、`節-機能-逆接`、`節-区切-補文`、`用言` 等标签；例如 `ふけっていようと` 标为逆条件和意志，`扱われます` 标为丁寧表达，`支払わなければならない` 标为强评价。标签应作为来源证据进入候选评分，不能直接替代 UniDic 的词形组合或语法义项决定。KWJA 的读法和词界存在错误，查询与词汇身份继续以 UniDic 为准。

## 查询和聚合暴露的边界

查询结果证明应用必须同时保留出现形、基本形和词元形。`霽れ` 的出现形没有命中，基本形 `霽れる` 命中一条，词元 `晴れる` 命中三条；`扱わ`、`後ろめた` 也只有还原形有稳定结果。`白南風` 有两个词典记录，`すね` 同时出现 `脛`、`臑` 等记录，表记组需要保留读音和词典可用性，不能以单一命中覆盖歧义。

旧字形和未知词需要独立记录。`雜` 没有 UniDic 词元和读音，查询仍通过规范表记得到 `雑(雜)`；`ラティメリア`、`ゾワゾワゾワ` 属于未知或拟态词，应该保留正文词元，查询层给出缺少读音或词典记录的状态。

`耳を傾ける`、`耳 を傾ける` 和跨空行的 `耳\n\nを傾ける` 不应得到相同的成立判断；表达识别需要检查字符间隔、段落和引号边界。`手を引く` 的字面义和惯用义需要词汇整体、句法角色和上下文共同判断。

## P4 应采用的对象分层

### 形态组合图

以 UniDic 词元为节点，新增有向边和链对象：

1. `token` 保存原子字段、出现范围和查询形。
2. `operator` 保存一个活用或功能操作的输入成员、输出状态、连接条件和证据。
3. `chain` 保存连续成员范围、词汇核心或功能用言所有权、显示原型、辞书形和查询形。
4. 来源诊断字段可保留 GiNZA 的 `sub_tokens`，用于排查模型行为；它不生成新的正文词元、聚合成员或查询目标。

链构建先依据 UniDic 的词性、活用型、活用形、词首／词尾结合字段和成员连续性，再读取 KWJA 的谓语标签作为上下文证据。`非自立可能`、`助動詞`、`助詞` 应统一进入功能身份候选；最终所有权由链规则决定。

### 构词和词汇整体候选

候选来源分为 GiNZA compound、KWJA 基本句／实体提示、UniDic 构词字段与词元序列、词典反向验证四类。每个候选保存整体范围、正式 token 成员、读音拼接、词典验证、来源证据和状态。状态采用 `observed`、`candidate`、`pending`、`rejected`，来源观察和应用决定分开保存。

竞争候选先按完整范围、正式 token 覆盖和词典记录排序。`教科用図書`、`神戸市` 等整体词可以在词典记录确认后生成阅读单位；`見渡す`、`這い上がる` 按单个正式 token 查询，A／B 成分不进入应用对象。

### 语法实例

语法识别消费形态组合图、KWJA 结构标签和句法范围。识别、义项选择和解释投影分三个步骤：

1. 识别阶段只产生候选，引用具体词元、operator、基本句和小句标签。
2. 义项阶段使用接续形式、句法功能、语域、前后范围和反例条件选择 `sense`；模型标签只作为加权证据。
3. 投影阶段生成精确成员范围、整体外包范围、捕获变量和待定原因，供正文高亮、查词和讲解共同引用。

代表规则应覆盖 `掲載された`、`発展せしめる`、`ふけっていようと`、`支払わなければならない`、`扱われます`、`読んでくださった`、`見渡すが`、`覗かれてる`、`専有してしまっている`。每条规则同时记录正例、反例、连接条件和来源字段。

### 表达识别

连续表达必须检查相邻成员的字符范围确实相接，或只跨越规则允许的空白。非连续表达保存多个成员范围和 gap 条件，硬边界包括句界、段界、引号域和用户明确禁止的空白。字面连续命中先进入候选，惯用义需要词汇整体、句法角色或目录反例共同确认。

## 下一阶段验收重点

P4 的第一轮实现应直接使用本轮样本建立回归集：活用链检查五组连续形式，正式 token 聚合检查 `見渡す`、`這い上がる`、`線状降水帯`，整体聚合检查 `教科用図書`、`神戸市`、`方向転換`，旧字形和缺少读音检查 `雜`、`霽れ`、`ゾワゾワゾワ`，语法候选检查文语、受身、使役、义务、丁寧、逆条件和补助用言。

每个用例需要同时检查原文范围、成员身份、查询形、来源证据、候选状态、解释义项和最终投影。KWJA 关系保留在来源层，只有在候选规则声明依赖时才进入应用决定；来源关系本身不作为语法命中的充分条件。
