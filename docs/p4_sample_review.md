# P4 完善验收报告

日期：2026-09-22。核心验收范围为 token、语法活用链及整体构词。实现契约见 [P4 活用链与整体构词](p4_morphology_formation.md)；开发基线保存在 [来源审计](p4_layer_audit.md)。

## 实现结果

UniDic token 保留原始词法字段、出现形及基本形查询证据。状态机按词类、连接形和字符连续性生成活用链，覆盖五段、一段、カ变、サ变、形容词、形状词及系词；局部转移支持使役、语态候选、否定、过去、敬体、愿望、条件、命令、禁止和补助用言。链保存核心成员、功能所有权、父链和有序 operator，形态 occurrence 保存精确成员、命中区间和上下文范围。

缩约规范形式采用 `ている／てしまう／ておく`，查询形采用 `いる／しまう／おく`。`てる／でる`、`ちゃう／じゃう`、`とく／どく` 的缩略、浊化及活用保存在原始成员和连接信息中。`読んでいる` 的补助 occurrence 包含前项的 `で`；`専有してしまっている` 保存两级父链和各自接续成员。

整体构词主要依据 GiNZA 正式 token 和显式 compound，与 UniDic 成员对齐。`FormationNode.word` 提供词头、核心成员、内部查询引用、关联链、查询形及来源。部分覆盖或含功能成分的范围标为 pending，核心词性存在分歧时标为 candidate。查询服务返回目标身份及 `matched/no_match`；整体对象的 `not_checked` 表示该分析产物尚未进行词典验证。

依存、文节和 KWJA 句法信息用于实验与辅助复核。依存提出的跨 token 整体保留 candidate；来源节点和关系引用通过程序校验。P4 的完成结论依据 token、活用链与整体构词的实际行为。

## 查询与语言边界

实际 `QueryCandidate` 调用中，`方向転換`、`扱われます → 扱う`、`這い上がる` 返回 matched；`教科用図書`、`神戸市`、`線状降水帯` 返回 no_match。整体无记录时，内部 token 查询引用继续有效。

读音拼接保留 composed 字段证据。P02 `送梅` 的来源拼接为 `オクウメ`，P06／P07 的数词包含逐字读音；这些结果属于待复核的查询证据。词典确认和专门的数词读法处理由后续消费方完成。语态 occurrence 保留受身、可能、尊敬、自发候选，具体语境义项由语法解释阶段选择。

旧字预处理采用 `kyujitai.js` 字符表，将 `雜／搖` 转为 `雑／揺` 后分析，准备映射保留原文位置。第三方来源与目录索引见 [sources.md](../sources.md)。
