# Kotoclip UI 风格流派与设计思路总结

状态：2026-08-02，基于 `src/components`、`src/styles` 源码静态审计。范围：阅读菜单、书库、悬浮气泡、词典解析展示。本文件只做抽象判定与意图分析，不包含样式规则。

## 1. 风格流派判定

Kotoclip 的 UI 属于一个少见的组合：**“文本优先的安静界面（Text-first Calm UI）”为骨架，“纸与玻璃”的材质二元论为皮肤，“杂志式极简（Editorial Minimalism）”为门面**。

- 它不是“工具型界面”：没有一个屏幕在宣称“这是一个查词软件”。书库是书架，正文是书页，查词是停留在正文上的动作，菜单是从阅读中临时抽身的走廊。
- 它不是“装饰型界面”：不存在为好看而存在的大图、插画层、动效秀。所有视觉投入都服务于“别打断我读书”与“让我看清分析结构”这两件事。
- 它也不是“数据看板”：分析结果不以表格、图表、侧栏树呈现，而是以正文自身的形态变化（隐形、浮现、下划线、徽章）表达。

一句话：**这是一个把“辅助”做成动词的阅读器——一切界面都围绕“正在读”这个动作生长，用完即隐。**

## 2. 设计思路（抽象层）

1. **干扰预算（Interference Budget）**
   整个界面像在管理一笔视觉干扰预算：默认支出为零，每一次交互才支付一次。胶囊默认透明、菜单默认收起、进度默认不打扰。设计的隐藏目标不是“功能可达”，而是“干扰可赎回”——任何辅助都可以被瞬间解除（已掌握的词脱下胶囊、Esc 关闭一切、静音章节）。

2. **形态即语义（Form Follows Meaning）**
   交互模式与视觉形态一一绑定，不重复、不混用：生词程度用三种边框语言（实线/虚线/点线），判别式选择用下划线 tab，单选切换用 pill，数值调节用滑块。用户不需要读文字就能知道“这是哪种动作”，这是界面内的语法。

3. **材质承担层级（Material as Hierarchy）**
   信息层级不靠边框粗细和颜色深浅堆叠，而靠材质：纸面 = 正在读的内容，玻璃 = 悬浮的辅助，实色面板 = 临时的工作台。三层材质构成三种“注意力温度”，比任何视觉样式表都稳定。

4. **来源即身份（Source as Identity）**
   词典内容聚合检索，但每一本词典保留自己的排版指纹（大辞林的 ruby 与分类徽章、小学馆的义项行、Crown 的译语与对照卡）。聚合的是检索，不抹平的是来源——这既是信任设计，也是内容态度的表达。

5. **过渡即导航（Transition as Wayfinding）**
   “打开一本书”不是一个跳转而是一条连续路径：书架上点封面 → 水波扩散 → 光晕波环 → 居中图标 → 浏览器过渡动画进入阅读页。物理连续性让用户始终知道自己在书的哪个位置、从哪来。

## 3. 组件样式 / 交互模式对应

### 3.1 阅读菜单 —— 临时工作台

| 组件/交互 | 形态与模式 | 对应思路 |
| --- | --- | --- |
| ReaderSurface 三态 | 侧栏 360px 贴边 / 模态 420px 右上角 / 全屏 | 按任务心智重量分配容器：轻任务贴边、中任务角落、重任务全屏 |
| 章节导航 | 序号列 + 层级缩进列表，active 浅底 | 形态即语义：位置感只用“数字+缩进”表达 |
| 排版面板 | 四根滑块 + 实时数值回显 | 数值调节语义，无预设方案的自由感 |
| 词典设置 | 可见序号的拖拽排序 + 默认徽章 | 透明化优先级，拖拽即“第一词典=默认”的规则可视化 |
| 待导出词汇 | 内联笔记卡 + 计数徽章 + 底部固定操作栏 | 收集是阅读的延伸，笔记不离开卡片 |

### 3.2 书库 —— 内容入口

| 组件/交互 | 形态与模式 | 对应思路 |
| --- | --- | --- |
| 继续阅读横卡 | 2 卡一页 + 圆环进度 + 边缘箭头 | 回到正文优先于浏览书架；圆环表达“完成度”而非“已读量” |
| 封面网格 | 3:4 网格 + hover 上浮 + 右下角渐显操作钮 | 安静网格，操作藏在悬停里 |
| 导入卡 | 双操作分色扩散 + 水波 | 把“带内容进来”做成有触感的动作，本地优先的产品主张 |
| 上下文菜单 | 玻璃浮层 + 六色 swatch + 标签编辑 | 组织语义（颜色=用户分类）与功能操作分层 |
| 打开书过渡 | ripple → 波环 → 图标 → view-transition | 过渡即导航：保持“进书”的物理连续 |

### 3.3 悬浮气泡 —— 就地解释

| 组件/交互 | 形态与模式 | 对应思路 |
| --- | --- | --- |
| 词典气泡 | 玻璃壳 + sticky 双列头 + 定义区 | 就地解释：不离开正文位置完成全部查询 |
| 三条选择条 | 表记/词典/词条，pill + kbd + 星标 | 聚合透明化：把“谁命中、哪个表记、哪个义项”摊开给用户 |
| 双面板 | 内部词形 + 整体词并排 | 解释目标协议的产品化：NLP 切分与读者直觉不一致时两个通道并存 |
| 语法气泡 | 下划线 tab + 形态卡 + 页脚信任徽章 | 判别式选择与信息溯源分离：结论可查来源 |
| 140ms 关闭宽限 | 指针出入气泡/正文互不打断 | 干扰预算的赎回：移动指针不惩罚用户 |

### 3.4 词典解析展示 —— 内容表现

| 组件/交互 | 形态与模式 | 对应思路 |
| --- | --- | --- |

## 4. 区分性体验与意图（重点分析）

以下体验不是“做得好”，而是**做了别人不做的选择**，是产品的区分点：

### 4.1 隐形胶囊系统：正文即分析界面
- 表象：分析结果以“默认透明、hover 浮现、已掌握即脱下”的胶囊长在正文里。
- 意图：a) 把“查词”从工具动作降格为阅读动作，维持整本阅读的心流；b) 用“胶囊—脱下”的物理隐喻，让抽象的学习状态（陌生→熟悉→掌握）变成可见的文本形态，形成“读得越多，界面越干净”的正反馈；c) 这是对“高亮分级”类学习工具的升级——别人给词上色，Kotoclip 让颜色在掌握后消失。

### 4.2 双面板词典气泡：为分析误差而设计
- 表象：同一锚点上，内部词形与整体词两个通道并排。
- 意图：承认 NLP 切分与读者直觉可能不一致（`第／一／話` 该查谁？），用双通道消解“查不到”的挫败，而不是用单一结果掩盖误差。这是把技术不确定性直接转译成界面容量的做法，同类工具罕见。

### 4.3 三条选择条：反黑箱的查词
- 表象：表记 × 词典 × 词条三层横向选择条，全部可点、可切换、可快捷键。
- 意图：多词典聚合通常做成“一个神秘答案”，Kotoclip 选择把命中矩阵完全摊开，用户能看到“哪本词典在哪个表记下命中”，并能亲手换词典。这是把信任建立（来源可查）做成交互本身，而不是靠免责声明。

### 4.4 书库的“继续阅读优先”结构
- 表象：继续阅读横卡（圆环进度）位于一切之上，书架网格退居其后。
- 意图：产品把“回到正文”当成第一任务，圆环是完成度而非阅读量——激励是“读完它”而不是“读得多”。这与本地优先、整本阅读的产品定位互为表里。

### 4.5 ReaderSurface 三态：按心智重量给容器
- 表象：章节/导出用贴边侧栏，排版/词典设置用右上角模态，语法库/审计用全屏。
- 意图：任务越重，容器越大；但三种容器都是“用完即走”的临时态，正文始终是唯一常驻。这维持了“阅读是主场”的层级，菜单永远只是过道。

### 4.6 引导页的“高表现力门面”
- 表象：杂志式大标题、每页换色调、噪点光斑、几何插画、游戏化进度，与使用面的克制形成强烈反差。
- 意图：首启是唯一的“宣传时刻”——用高表现力建立“这是给爱读整本书的人的工具”的定位，随后立刻退场，把安静还给阅读。宣传面与使用面的二元对立本身就是设计声明。

### 4.7 E-ink 整机降级：把阅读器当真阅读设备
- 表象：完整黑白、去材质、去动效的降级模式。
- 意图：不是兼容性补丁，而是安静技术的极端化——承诺“即使在墨水屏上，这个工具也只是纸和字”。它让“低干扰”从风格变成可验证的设备级承诺。

### 4.8 词典来源指纹（style_profile）
- 表象：三本词典各自排版，共用同一套材质变量。
- 意图：在一个聚合浮层里保留每本词典的体感，是对“词典是权威来源”的尊重，也是多来源产品的信任架构——用户永远知道自己在读谁的内容。
