# 用户状态与输出

## 状态所有权

用户数据由本地 SQLite 与书库文件保存。语言分析提供词元及正文实例，个人状态通过稳定身份附加到阅读投影。

| 数据 | 作用域与用途 |
| --- | --- |
| 已知／未知、熟悉度 | 词元知识身份，影响词汇提示 |
| 曝光记录 | 文档出现与阅读会话，记录实际展示的内容 |
| 汉字知识 | 从明确的词汇状态与读音证据派生 |
| 词典顺序与默认选择 | 用户偏好，决定查询列及初始活动词典 |
| 实例修正 | 具体出现锚点、原分析签名与用户选择 |
| 收藏与笔记 | 知识目标、正文出处、用户文本及创建时间 |
| 阅读位置与排版 | 书籍状态及本机显示偏好 |

知识身份、出现身份和界面临时选择分别管理。缓存重建、后台分析和界面重新渲染使用同一出现记录去重，曝光依据实际阅读范围写入。

## 个人操作

已知状态、收藏和实例修正提交实体引用、会话及预期版本。后端校验后持久化并返回受影响的投影更新。批量操作在一个事务内完成，响应携带实际成功和失败对象。

词汇状态变化刷新相关词汇显示；语法和表达继续按各自知识身份展示。汉字熟悉度由用户词汇证据推导，并保存来源关系以支持撤销后重算。

实例修正保存原分析签名、出现锚点、所选结构或解释及撤销状态。文本或模型更新后检查修正是否仍可定位，失效记录进入待复核状态。

## 数据迁移

已有画像按原始词头、读音、词性和出处映射到新身份。明确匹配的记录继续使用；有歧义的记录保留原值及映射状态，供后续复核。

迁移使用版本化事务并保留恢复副本。再次执行具有幂等性。词典缓存、语言分析缓存、用户画像和书庫索引分别管理生命周期。

## 选择、收藏与导出

正文选择绑定实体及实际字符范围，跨阅读单位选择保留成员次序。收藏在关闭文档后持续可用；导出可以从当前选择或已保存内容生成。

导出记录包含实际表记、查询形、读音、词性、语法／表达说明、等级信息、上下文、精确高亮、释义来源和用户笔记。非连续表达按多个命中范围保存。去重采用知识身份并保留出处，JSON 同时记录格式版本与正文摘要。

输出内容通过统一查询目标获取。导出前检查目标版本、词典记录和上下文范围；资源缺失时返回可辨认的状态，已保存的用户内容继续可访问。

## 词典助手

词典助手由用户主动触发，输入当前上下文、词法证据及已有词典候选，返回候选引用、依据和未决状态。结构化响应经过 schema、候选身份和范围检查后展示。用户采用建议时生成可撤销的实例修正。

服务端点、模型和凭据在本机配置。请求只包含该任务所需上下文；凭据由宿主管理，日志屏蔽敏感字段。超时、取消、无效响应和服务不可用均结束于本次助手任务，本地阅读与查询继续可用。

## 验收与入口

验收覆盖重启后的已知状态、重复曝光去重、实例修正及撤销、收藏恢复、中文路径导出、上下文高亮和助手异常。已有数据库迁移采用副本验证数据数量与身份映射。

[profile](../crates/kotoclip-core/src/profile/)保存画像与用户状态基础，[export](../crates/kotoclip-core/src/export/)保存输出基础，[llm](../crates/kotoclip-core/src/llm/)保存结构化助手接口。[ExportPanel.vue](../src/components/ExportPanel.vue)和[dictionaryAssistantPort.ts](../src/services/dictionaryAssistantPort.ts)提供对应前端入口基础。
