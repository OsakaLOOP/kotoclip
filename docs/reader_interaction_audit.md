# 阅读渲染与气泡交互排查

本次按 Prevent 原则修复阅读界面的范围、更新和交互问题。采用源码审查与静态检查，交互验收由用户完成，不运行测试。

## 首要问题

| 问题 | 期望行为 | 实际原因 | 修复状态 |
| --- | --- | --- | --- |
| 多段正文重复 | 每个正文块只输出自身字符范围，按原顺序显示一次 | `partsFor` 收集全文胶囊边界，仅对起点取最大值、终点取最小值；不相交范围产生段外切分点，每个块因而输出其他块正文 | 已限制参与切分的范围，并在段内裁剪；待交互验收 |
| 灰色细体与蓝色粗体混杂 | 普通正文继承正文样式，Markdown 标题采用蓝色粗体；可交互性由当前分析目标决定 | 越界正文继承当前 `p` 或 `h2` 的样式，而查询命中仍受原块范围约束；复制后的纯文本失去标题语义，样式随之变化 | 与范围修复同步消除越界样式；保留合法标题语义，待交互验收 |
| 分析卡顿、完成时滚动跳动 | 分析结果局部更新，正文折行与阅读位置稳定 | 会话空轮询替换对象；每次更新重复推导所有驻留单元；胶囊添加间距和边框改变折行；重复正文放大行高变化 | 已完成空更新复用、单元投影复用、可见段落复用及过期投影释放；排版与调度继续修复 |

## 气泡及其他发现

| 问题 | 期望行为 | 实际原因 | 状态 |
| --- | --- | --- | --- |
| 返回外围整体 | 查询所属外层目标 | 按钮再次查询 `activeHit`，可能仍为内部 token | 待修复 |
| 非整体单击细分 | 单击核心词后进入底层 token，保留返回入口 | 悬浮投影优先生成核心子目标，点击只检查该子目标的空 children | 待修复 |
| 气泡迟到响应 | 只更新仍有效的会话、单元和目标 | 目标失效与卸载未统一关闭气泡；词汇状态异步结果缺少请求代次校验 | 待修复 |
| 补充平面字符选择 | 选择、收藏和进度使用 Unicode scalar 坐标 | DOM 选择偏移和字符串长度使用 UTF-16，与分析坐标不一致 | 待修复 |

## 人工验收

1. 输入含标题、空行和连续换行的 A／B／C 三段文本，等待逐段完成，确认顺序、字数与可交互范围。
2. 对比标题内文字与正文内文字；复制正文作为新文本分析，确认普通正文样式稳定。
3. 在长书中停留于段落中部，等待后续单元完成；滚动、切换章节、调整字号后继续观察定位。
4. 悬浮核心词与活用部分，进入词典和说明气泡，单击非整体词、切换 token、返回外围整体。
5. 快速切换词语、返回书库、重试分析，确认释义及已知状态始终属于当前词。
6. 选择包含 `𠮷` 等补充平面字符的正文并保存，核对选中文本与字符范围。
