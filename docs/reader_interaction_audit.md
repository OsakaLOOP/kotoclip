## 样式与滚动的次要原因

- 作者注音依赖片段范围完全相等，词汇或活用切分进入注音范围后会使注音消失。现按作者注音建立稳定的 ruby 容器，内部保留各自查询目标，分析前后保留完整读音。
- 胶囊的 margin、padding 和 border 会在分析完成时改变字符间距。现采用不占布局空间的 outline 显示悬浮边界，普通正文的字号、字重和颜色持续继承段落样式。
- 滚动容器具有 42px 顶部留白，但虚拟列表原先以 0 作为首行位置；现统一坐标。关闭浏览器滚动锚定，由虚拟列表补偿完全位于视口上方的行高变化，保留稳定滚动条宽度。
- 每次组件更新都会重新测量同一 DOM 行。现仅在节点注册及 ResizeObserver 通知尺寸变化时测量，图片完成加载保留专门的测量入口。
- 文本行高原先固定估算为两行，长段落和短段落均存在明显误差。现按正文长度、显式换行、版心宽度、标题字号与段距估算，挂载后使用实际尺寸。
- 当前阅读页面通过 `ReaderDocumentView.vue` 渲染，`AnalyzedTextItem.vue`、`BunsetsuCapsule.vue` 与 `segmentColoring.ts` 属于其他保留入口。当前正文样式仅区分普通段落和 Markdown 标题；主题与墨水屏模式统一调整配色。
- 范围请求原先取消活动分析、提升代次并返回完整快照。现合并连续滚动请求，范围调整只改变优先队列；当前任务完成后处理新范围，响应采用增量更新。取消和重试保留代次失效语义。
- 已完成的可见范围原先不会更新后端保留范围，后台推进时可能释放用户正在阅读的产物。现可见范围变化后统一更新优先队列与保留范围；已释放单元重新进入队列，处理中单元保持运行，失败单元保留手动重试入口。暂停时保持暂停状态。
- 可见范围监听原先每次返回新数组，滚动位置变化会重复同步相同范围。现逐项监听会话版本及范围端点；ResizeObserver 已提供尺寸时直接使用该值，减少重复布局读取。
- 后端重排优先队列使用不断增长的 `contains` 扫描，单元数增加时达到平方级工作量。现直接拼接优先区间外的索引，保持线性遍历；继续分析复用已有的完整队列。

## 人工验收

1. 输入含标题、空行和连续换行的 A／B／C 三段文本，等待逐段完成，确认顺序、字数与可交互范围。
2. 对比标题内文字与正文内文字；复制正文作为新文本分析，确认普通正文样式稳定。
3. 在长书中停留于段落中部，等待后续单元完成；滚动、切换章节、调整字号后继续观察定位。
4. 悬浮核心词与活用部分，进入词典和说明气泡，单击非整体词、切换 token、返回外围整体。
5. 快速切换词语、返回书库、重试分析，确认释义及已知状态始终属于当前词。
6. 选择包含 `𠮷` 等补充平面字符的正文并保存，核对选中文本与字符范围。
7. 等待百余单元文本全部完成，再跳转到较早和较晚段落；确认新增恢复任务计入缓存总数，已分析次数保留，缓存读取以计算单元的 1/4 权重更新进度条。
8. 从词语向前、向后及跨行拖至同段另一词语，确认高亮与合并释义；原地单击仍可细分，从空隙开始拖动可复制或收藏正文。Escape、滚动和会话失效会取消拖拽。

合并查词采用用户选定的连续正文表记，范围限制在同一段落，沿用词典搜索的 1–100 字符限制。合并查询与关联词查询使用同一词典表记切换及返回历史；超出限制时显示查询错误。

## 进度计数约定

总任务数和剩余任务数按计算、缓存读取直接相加；进度条比例为 `(已分析 + 已缓存 / 4) / (分析总数 + 缓存总数 / 4)`。同一单元再次从缓存读取时累计一次缓存任务。尚未核实缓存的首次任务暂计入分析总数，确认命中后归入缓存；缓存缺失而实际完成计算时归入分析。失败任务保留在对应总数中，成功重试后累计完成数。来源更新会安排新的分析任务，保留本次会话的已完成次数。
